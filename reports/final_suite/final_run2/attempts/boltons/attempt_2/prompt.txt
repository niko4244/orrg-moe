## Issue

`isoparse` in `boltons/timeutils.py` mishandles fractional seconds.

`isoparse('1970-01-01T00:00:00.851')` must produce microsecond 851000 (851
thousandths of a second), but it produces 851. The fractional digits after the
decimal point are a decimal fraction of one second and must be scaled to
microseconds: one digit means tenths, three digits mean thousandths, six digits
mean millionths.

More than six fractional digits must truncate to microsecond precision instead
of raising `ValueError: microsecond must be in 0..999999`; for example
`.123456789` must produce microsecond 123456.

Plain timestamps with no fraction, and timezone suffixes such as `Z` and
`+05:30`, must keep working unchanged.

## Current implementation of `isoparse`

This is the version that produced the results below:

```python
def isoparse(iso_str):
    """Parses the limited subset of `ISO8601-formatted time`_ strings as
    returned by :meth:`datetime.datetime.isoformat`.

    >>> epoch_dt = datetime.fromtimestamp(0, timezone.utc).replace(tzinfo=None)
    >>> iso_str = epoch_dt.isoformat()
    >>> print(iso_str)
    1970-01-01T00:00:00
    >>> isoparse(iso_str)
    datetime.datetime(1970, 1, 1, 0, 0)

    >>> utcnow = datetime.now(timezone.utc).replace(tzinfo=None)
    >>> utcnow == isoparse(utcnow.isoformat())
    True

    For further datetime parsing, see the `iso8601`_ package for strict
    ISO parsing and `dateutil <https://pypi.python.org/pypi/python-dateutil>`__
    package for loose parsing and more.

    .. _ISO8601-formatted time: https://en.wikipedia.org/wiki/ISO_8601
    .. _iso8601: https://pypi.python.org/pypi/iso8601

    >>> isoparse('1970-01-01T00:00:00.851')
    datetime.datetime(1970, 1, 1, 0, 0, 0, 851000)

    Timezone suffixes (``Z``, ``+HH:MM``, ``-HHMM``, and so on) yield
    timezone-aware datetimes, so aware
    :meth:`~datetime.datetime.isoformat` output round-trips, too.

    >>> isoparse('1970-01-01T00:00:00+05:30')
    datetime.datetime(1970, 1, 1, 0, 0, tzinfo=datetime.timezone(datetime.timedelta(seconds=19800)))
    >>> aware_now = datetime.now(timezone.utc)
    >>> aware_now == isoparse(aware_now.isoformat())
    True

    """
    tzinfo = None
    tz_match = _ISO_TZ_RE.search(iso_str)
    if tz_match:
        iso_str = iso_str[:tz_match.start()]
        tz = tz_match.group(1)
        if tz == 'Z':
            tzinfo = timezone.utc
        else:
            digits = tz[1:].replace(':', '').split('.')[0]
            hh, mm = int(digits[0:2]), int(digits[2:4])
            ss = int(digits[4:6] or 0)
            sign = -1 if tz[0] == '-' else 1
            tzinfo = timezone(sign * timedelta(hours=hh, minutes=mm,
                                                seconds=ss))
    parts = _NONDIGIT_RE.split(iso_str)
    dt_args = [int(p) for p in parts]
    microsecond = 0
    if len(parts) > 6:
        microsecond = int(parts[6])
    return datetime(*dt_args[:6], microsecond=microsecond, tzinfo=tzinfo)

```

## Repair hint

Fractional seconds are a fixed-width six-digit field. Append zeros on the right with str.ljust(6, '0'); never prepend them with str.rjust. Then slice to six characters and convert to int: '851'.ljust(6, '0') == '851000', '000001'.ljust(6, '0') == '000001', and '123456789'.ljust(6, '0')[:6] == '123456'. Do not use float arithmetic or multiply/divide after parsing. The result must be an int in 0..999999.
